# 🍲 麦麦治愈食堂（MCD Comfort Canteen）

> 情绪先被接住，才谈得上吃什么。

基于麦当劳中国官方 MCP 开发的情绪陪伴 Skill：你说出今天的疲惫、低落或烦躁，它**先接住情绪**（不诊断、不说教、不灌鸡汤），再给你 2-3 个可执行方案——吃饭只是其中之一。

![card](assets/demo-card.png)

> ⭐ **如果它接住过你，欢迎点个 Star** —— 大赛冲刺中（10-25 截止），每一颗星都让它被更多「加班到十点的人」看见。

## ✨ 它和别的麦当劳 Skill 有什么不同

| 别人在做 | 这个在做 |
|---------|---------|
| 怎么点得更快 | 今天很糟的时候，怎么照顾自己一顿 |
| 怎么算得更省 | 吃多少「刚刚好」，而不是放开吃 |
| 怎么吃得更健康 | 先接住情绪，再谈吃什么 |

## 🎬 一次完整对话

```
你：今天加班到十点，整个人都空了。

它：今天太长了，连选吃什么都累。
    空掉的感觉很具体，不是矫情。
    ─ 需要我帮你安排点什么吗？

你：好。

它：① 一顿饭｜热乎的，不用嚼太费劲
    猪柳麦满分 308 kcal + 热饮，一人份刚好，吃完不犯困
    ② 一件小事｜设 25 分钟倒计时，什么都不做
    ③ 一句话｜"今天剩下的部分，及格就行。"
    ─ 需要我帮你算一下价格吗？
```

## 🚦 安全设计（本项目最重要的一部分）

情绪陪伴产品的安全边界不是附加项，而是产品本体：

| 红线 | 实现 |
|------|------|
| 🚨 危机词触发热线 | `safety_guard.py` 在**调用 MCP 之前**执行，命中即短路，只输出 12356 / 12355 |
| 🚫 禁止心理诊断 | 只做情绪命名，绝不出现抑郁/焦虑症等判定 |
| 🚫 禁止鸡汤说教 | 明确禁用「明天会更好」「你已经很棒」等话术清单 |
| 🍽 反情绪性进食 | 吃饭只是 3 个方案之一；每次带热量与份量锚点；深夜自动降负担 |
| 🔒 数据本地 | 情绪记录不上传、不画像、不设社区与分享 |

详见 [SAFETY.md](SAFETY.md)。

## 🚀 安装

1. 激活 MCP Token：[open.mcd.cn/mcp](https://open.mcd.cn/mcp) → 手机号登录 → 控制台 → 激活
2. 配置 MCP：将 `mcp-config.example.json` 中的 `YOUR_MCP_TOKEN` 替换（WorkBuddy：连接器 → 自定义连接器 → 配置 MCP）
3. 说一句话即可开始
